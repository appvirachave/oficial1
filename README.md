# VIRA CHAVE — versão estática

Aplicativo estático para GitHub Pages. Extraia o ZIP e envie a pasta `vira_chave_app` ao repositório, mantendo `index.html` na raiz publicada.

**Importante:** esta versão é demonstrativa. Valores, saldo e solicitações ficam no navegador e não representam criptoativos reais nem enviam pagamentos Pix. Os botões dos planos abrem os links de checkout fornecidos.
